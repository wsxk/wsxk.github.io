# 写在前面<br>
了解一下经济学常识，至少看得懂表，知道其他人在说什么。<br>


# 1. M0、M1、M2<br>
**M0、M1、M2都是衡量社会中“钱有多少”的指标，区别主要在于这些钱的流动性：越容易马上拿来支付，层级越靠前。**<br>
```
M0: 手里的现金，通常指社会公众持有的纸币和硬币
M1（狭义货币）：随时能花的钱， M0+ 活期存款
M2（广义货币）：社会上大部分钱，M1 + 定期存款、储蓄存款等
```
`M2-M1` 通常被称为准货币，准货币增长过快，说明企业和居民都更倾向于储蓄。<br>


# 2. 国债<br>
国债有国债利率、国债价格、国债收益率3个指标。为了解释他们之间的区别，需要解释一级市场和二级市场的概念。<br>
美国国债市场分为一级市场和二级市场。**美国国债一级市场为发行市场，主要针对的是机构和零售投资者（竞争性参与者和申购额度被限制的非竞争性参与者），像各国央行购买美国国债，基本上都是在一级市场参与美国国债的拍卖。**<br>
央行在一级市场竞拍到美国国债以后，将来要在二级市场抛售。所以，美国国债二级市场是极其活跃的，流通性非常好。对普通个人而言，都是在二级市场购买国债<br>
```
国债利率：国债在政府发行时确定的利率，比如政府发现了一张1000美元的国债，为期三年，国债利率5%，即每年固定支出1000* 5% = 50美元。
国债价格：政府发行的国债通常是一级市场，其他央行或者美联储买了国债后，可以选择放到二级市场销售，二级市场销售的价格就被称为 国债价格，国债价格可以是995美元，1000美元、1005美元等。
国债收益率： 对个人而言，你如果以 800美元买入一张国债，持有一年后，以900美元的价格卖出，对你而言，净收益（-800+50+900=150）美元，实际国债收益率为 150/800 =  18.75%
```

# 3. 最低上落价位<br>
“最低上落价位”就是港股的最小报价变动单位，也称**tick size**。它规定买卖盘价格每次至少相差多少，并不是限制股票一天最多涨跌多少<br>

| 股价范围      |  原最小变动 |         调整后 |
| --------- | -----: | ----------: |
| 0.50–10港元 | 0.01港元 | **0.005港元** |
| 10–20港元   | 0.02港元 |  **0.01港元** |
| 20–50港元   | 0.05港元 |  **0.02港元** |

比如说价值8港元一股的股票，调整前可以报价`8.01 , 8.02 , 8.03`港元，调整后可以报价`8.005 , 8.010 , 8.015`港元<br>

# 4. CPI和PPI<br>
消费者物价指数（Consumer Price Index，CPI）是衡量特定一定范围内消费品和服务价格变化的指针<br>
生产者物价指数（Producer Price Index，PPI）是衡量生产者支付的原材料和生产成本的指标。<br>
当CPI上升时，这通常表明通胀率上升，反之亦然。<br>
通常，当PPI上升时，这可能表明最终产品的价格也会上升。<br>

# 5. 市盈率<br>
`Price-to-Earnings Ratio`，公式为:<br>
```
PE = 每股股价/每股收益EPS
EPS = 归属于普通股股东的净利润​/流通股数
近似的看， PE = 公司总市值/公司净利润

TTM PE(Trailing Twelve Months，中文叫滚动市盈率),是指用公司当前的总市值除以最近连续12个月（即最近4个季度）的净利润计算出来的市盈率.
```

# 何时买入<br>
一般情况下，选定是美股的条件下:<br>
一看公司市占率是否足够高（市占率高说明利润高）<br>
二看公司的盈利是否好<br>
三看公司是否有可持续性、成长性。<br>
四看公司是否符合大发展方向、产品是否为人们必须<br>

满足上述四者，找个低点买入即可。<br>

# 何时卖出<br>
个人认为卖出的时机比买入时机更难把控，原因在于你需要判断未来某段时间内，公司是会继续涨，还是会跌。<br>
1、最重要：公司的基本面开始变差<br>
2、第二重要：股价上涨速度远超过盈利<br>
3、仓位变得太大，也是卖出理由<br>
